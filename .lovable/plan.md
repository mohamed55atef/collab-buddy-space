
# خطة تطوير "Everyday Fitness" — منتج جاهز للبيع للكوتشز والمراكز

## 🎯 الهدف
تحويل الموقع الحالي (موقع تغذية ولياقة عام بالعربي) إلى **منصة White-Label** قابلة للبيع لـ:
- مراكز اللياقة البدنية (Gyms)
- كوتشز التغذية (Nutrition Coaches)
- كوتشز الفتنس (Personal Trainers)

كل عميل (كوتش/مركز) يقدر يخصص الموقع باسمه، ألوانه، لوجوه، ويتابع عملاءه من لوحة تحكم.

## 🧹 المرحلة 0: تنظيف الملفات غير المستخدمة

### الملفات اللي هتتمسح:
**1) قالب React/Vite بالكامل (مش مستخدم في الموقع الحالي):**
- `src/` بالكامل (App.tsx, main.tsx, components/ui/*, pages/Index.tsx, NotFound.tsx, hooks, lib, test)
- `index.html` الخاص بـ Vite (لو موجود في root كقالب React) — لكن هنحتفظ بـ `index.html` الحالي بتاع الموقع
- `package.json`, `vite.config.ts`, `tsconfig*.json`, `tailwind.config.ts`, `postcss.config.js`, `eslint.config.js`, `vitest.config.ts`, `components.json`
- `public/placeholder.svg`, `public/robots.txt` (لو مش مستخدمين)

**2) ملفات مكررة/مجزأة بدون داعي (الأجزاء part1/2/3/4 المنفصلة موجودة كملفات مدمجة بالفعل):**
- `pages/calories-part1.html` → `calories-part4.html` (الأصل `calories.html` كافي)
- `pages/exercise-database-part1.html` → `part4.html`
- `pages/food-database-part1.html` → `part4.html`
- `pages/meal-plan-part1.html` → `part4.html`
- `pages/tips-part1.html` → `part3.html`
- `pages/workout-plan-part1.html` → `part4.html`
- نفس الشيء في `css/` (كل ملفات `*-part1.css` → `*-part4.css` لو الأصل المدمج موجود)
- نفس الشيء في `js/` (ملفات `*-part1.js` → `*-part4.js`، `main-part1.js`, `main-part2.js`, `style-part1.css`...)
- `js/workout-plan-new.js` (يستخدم `document.write` — anti-pattern)

- `data/*-1.js` المكررة مع نسخ `.json` (نوحدها على JSON)

**3) ملفات/مجلدات غريبة:**
- `city` (ملف بدون امتداد/غامض)
- `images/*.txt` (placeholder نصي بدل صور حقيقية)

**سياسة المسح:** هنتأكد قبل المسح إن كل ملف فعلاً مش مستدعى من أي HTML. لو ملف `partN` مستدعى من مكان، هندمج محتواه في الأصل ونحدّث المراجع.

## 🚀 المرحلة 2: مميزات المنتج القابل للبيع

### 2.1 نظام White-Label / Branding
- ملف `config/branding.json` فيه: اسم البراند، اللوجو، الألوان الأساسية، روابط السوشيال، رقم الواتساب، بيانات الكوتش
- كل النصوص اللي فيها "Everyday Fitness" تتقرأ من الكونفيج
- شاشة Onboarding للكوتش يدخل فيها بياناته أول مرة

### 2.2 لوحة تحكم الكوتش (Admin Panel) — صفحة جديدة `pages/admin.html`
- تسجيل دخول الكوتش (Auth عبر Lovable Cloud / Supabase)
- إدارة العملاء: إضافة/تعديل/حذف عميل
- لكل عميل: عرض بياناته (وزن، طول، هدف، سعرات)، إنشاء خطة وجبات مخصصة، إنشاء جدول تمارين مخصص
- متابعة تقدم العميل (وزن أسبوعي، صور Before/After)
- رسائل/ملاحظات بين الكوتش والعميل
- Dashboard إحصائيات (عدد العملاء، نشطين، إيرادات...)

### 2.3 بوابة العميل (Client Portal) — صفحة جديدة `pages/client.html`
- تسجيل دخول العميل بكود/إيميل
- يشوف خطة الوجبات اللي عملها له الكوتش
- يشوف جدول التمارين بتاعه
- يدخل وزنه أسبوعياً + يرفع صور
- يحجز جلسة (Booking) مع الكوتش
- يتواصل مع الكوتش (Chat بسيط)

### 2.4 صفحة الباقات والاشتراكات — `pages/pricing.html`
- 3 باقات (شهري/3 شهور/سنوي) للكوتش لما يشتري المنتج
- صفحة Landing تسويقية للموقع نفسه (هدفها بيع المنتج للكوتشز)

### 2.5 صفحة حجز موعد — `pages/booking.html`
- العميل يحجز جلسة استشارة مع الكوتش
- تقويم بالأوقات المتاحة
- ربط واتساب لتأكيد الحجز

### 2.6 تحسينات على الصفحات الحالية
- **حاسبة السعرات:** إضافة حاسبة الماكروز (Protein/Carbs/Fat)، حاسبة كمية الماء، حاسبة نسبة الدهون
- **خطة الوجبات:** تصدير PDF، طباعة، مشاركة واتساب
- **جدول التمارين:** فيديوهات لكل تمرين (بدل صور فقط)، Timer للراحة بين السيتات، تتبع الأوزان
- **قاعدة بيانات الأكلات:** فلترة بالحساسية (نباتي، خالي من اللاكتوز، كيتو...)، Barcode scanner اختياري
- **نصائح:** قسم Blog كامل قابل للتحديث من لوحة الكوتش

### 2.7 صفحات تسويقية جديدة
- `pages/services.html` — خدمات الكوتش (تدريب أونلاين، خطط مخصصة، متابعة...)
- `pages/testimonials.html` — آراء العملاء + صور Transformations
- `pages/contact.html` — تواصل (واتساب، إيميل، فورم)
- `pages/store.html` (اختياري) — بيع منتجات (مكملات، إكسسوارات، كورسات)

### 2.8 تحسينات تقنية وتجربة المستخدم
- **PWA**: تحويل الموقع لتطبيق قابل للتثبيت على الموبايل
- **Dark Mode:** موجود جزئياً، نكمله لكل الصفحات
- **SEO:** meta tags لكل صفحة، sitemap.xml، structured data
- **سرعة:** lazy loading للصور، minify CSS/JS
- **Multi-language:** إضافة الإنجليزية بجانب العربية (لتوسيع السوق)
- **WhatsApp Floating Button:** زرار واتساب عائم في كل الصفحات
- **Analytics:** Google Analytics + Facebook Pixel للكوتش يتابع زواره

## 🗂️ المرحلة 3: Backend (Lovable Cloud)

عشان لوحة التحكم وبوابة العميل تشتغل، محتاجين:
- **Authentication:** للكوتش وللعملاء
- **Database tables:**
  - `coaches` (بيانات الكوتش/المركز)
  - `clients` (عملاء كل كوتش)
  - `meal_plans` (خطط الوجبات المخصصة)
  - `workout_plans` (جداول التمارين)
  - `progress_logs` (سجل تقدم العميل)
  - `bookings` (الحجوزات)
  - `messages` (رسائل بين الكوتش والعميل)
- **Storage:** لرفع صور Before/After واللوجوهات
- **RLS Policies:** كل كوتش يشوف عملاءه فقط، كل عميل يشوف بياناته فقط
